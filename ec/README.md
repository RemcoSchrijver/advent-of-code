# Everybody Codes directory

Here you can find the solutions to the Everybody Codes challenges,
each type of challenge has its own directory that contains the individual
years nested into it. 

The structure for the puzzles is the same as for Advent of Code 
each year comes with a nix file that can be used to install the 
dependencies, this will happen automagically if you use 
[nix-direnv](https://github.com/nix-community/nix-direnv) 
(flake support is required).

## ./stories
Have a look at the stories I tried, each year I tried has a small description
in the [README](./stories/README.md).
