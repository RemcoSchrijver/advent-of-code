# Everybody Codes - Story 1 

![](https://img.shields.io/badge/ducks%20🦆-3-yellow)

This story I tried to do in Rust, you'll need cargo to run the solutions.
To run a solution use the following command: `cargo run dayXX partX` 
Inputs can be stored in the `./input/` directory, test data in `./tests/`, every day
will be a directory, and every part is stored like `partX`, from 1-3.
If you want to run with the test data you can append the `--test` flag at the end of the command.
